# 0004 — Uang integer rupiah di aplikasi

## Status
Accepted

## Konteks
POS menangani uang rupiah dan tidak boleh tergantung pada floating point saat perhitungan subtotal, diskon, pajak, dan refund.

## Keputusan
DB memakai NUMERIC(12,2); aplikasi selalu menyimpan dan mengolah uang sebagai integer rupiah dengan helper roundHalfUp.

## Konsekuensi
Perhitungan lebih stabil, tetapi semua service harus konsisten dalam konversi string/number ke integer.

## Alternatif yang ditolak
Mengandalkan float atau Math.round yang salah untuk nilai negatif.
