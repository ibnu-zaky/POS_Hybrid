# 0002 — Monorepo npm workspaces

## Status
Accepted

## Konteks
Repo membutuhkan struktur yang jelas di apps/api, apps/web, dan packages/core agar kerja lint/test/build lebih konsisten.

## Keputusan
Gunakan npm workspaces di root, dengan satu root package untuk orchestrasi dan workspace-specific package.json untuk API/web/core.

## Konsekuensi
Perintah root lebih sederhana, tetapi import workspace harus ditulis dengan nama paket atau path yang jelas.

## Alternatif yang ditolak
Single-package monolith atau repo flat yang menumpuk semua service dalam satu folder.
