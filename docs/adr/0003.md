# 0003 — TypeScript gradual + ratchet checkJs

## Status
Accepted

## Konteks
Backend dan banyak file legacy masih CommonJS. Migrasi penuh ke TS terlalu besar dan berisiko.

## Keputusan
Aktifkan gradual TS di lint/checkJs, lalu menjaga baseline error tetap stabil; hanya file yang disentuh dipromosikan ke TS.

## Konsekuensi
Ada transisi bertahap tanpa memecah aliran kerja harian.

## Alternatif yang ditolak
Pindah seluruh codebase sekaligus atau menutup mata atas debt type-checking.
