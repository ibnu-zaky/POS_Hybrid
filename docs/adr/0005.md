# 0005 — Multi-tenant merchant_id + RLS

## Status
Accepted

## Konteks
Tenant leakage adalah risiko keamanan pada data pembukuan dan karyawan.

## Keputusan
Semua tabel penting memakai merchant_id, RLS, dan tenant context. Query hanya boleh berjalan bila merchant context aktif.

## Konsekuensi
Membutuhkan disiplin di semua query dan migrasi baru, tetapi isolasi data lebih kuat dan aman.

## Alternatif yang ditolak
Mengandalkan satu tenant global atau role check semata.
